================================================================================
       TELEGRAM BOT API CHANGELOG: [UI/UX] & [MESSAGES & FORMATTING]
================================================================================

SCOPE OF THIS FILE:
- [UI/UX]                 : Buttons, inline & reply keyboards, styles, menus,
                            theme colors, link preview controls, reaction controls
- [Messages & Formatting] : Rich messages, drafts & streaming, markdown/HTML,
                            entities, spoilers, quote replies, ephemeral messages

August 24, 2026 — Bot API 10.3
--------------------------------------------------------------------------------
[Messages & Formatting] Added RichMessageButton representing a button in a RichMessage.
[Messages & Formatting] Added RichTextButton.
[Messages & Formatting] Added RichBlockButtons and InputRichBlockButtons.
[UI/UX]                 Added field is_compact to RichBlockTable and InputRichBlockTable.
[UI/UX]                 Added RichBlockExpandableBlockQuotation and InputRichBlockExpandableBlockQuotation for collapsible block quotations.
[Messages & Formatting] Added EphemeralMessageParameters; replaced receiver_user_id and callback_query_id across sendMessage and media methods with ephemeral_message_parameters.
[Messages & Formatting] Added parameter ephemeral_message_parameters to sendRichMessage.
[UI/UX]                 Added replace_callback_query_message to EphemeralMessageParameters to display ephemeral messages in place of original messages.
[UI/UX]                 Added parameter show_caption_above_media to editEphemeralMessageCaption.
[Messages & Formatting] Added parameter rich_message to editEphemeralMessageText.
[UI/UX]                 Added DisabledButton and field disabled to InlineKeyboardButton.
[UI/UX]                 Added field force_reply to InlineKeyboardMarkup and ReplyKeyboardMarkup.
[Messages & Formatting] Added parameters can_stop and keep_on_stop to sendMessageDraft and sendRichMessageDraft.
[Messages & Formatting] Added updates for user stopping message generation (MessageGenerationStopped, Update.stopped_message_generation).

--------------------------------------------------------------------------------
July 14, 2026 — Bot API 10.2
--------------------------------------------------------------------------------
[Messages & Formatting] Added InputRichMessageMedia and field media to InputRichMessage for explicit media formatting.
[UI/UX]                 Added InputRichBlockListItem for items in rich message lists.
[UI/UX]                 Added formatting block components: Paragraph, SectionHeading, Preformatted, Footer, Divider, MathematicalExpression, Anchor, List, BlockQuotation, PullQuotation, Collage, Slideshow, Table, Details, Map, Animation, Audio, Photo, Video, VoiceNote, Thinking.
[Messages & Formatting] Added field blocks to InputRichMessage to format messages using block entities.
[Messages & Formatting] Introduced Ephemeral Messages (visible only to specified user and bot) for group interactions.
[Messages & Formatting] Added field is_ephemeral to BotCommand.
[Messages & Formatting] Added receiver_user and ephemeral_message_id to Message.
[Messages & Formatting] Added receiver_user_id and callback_query_id to all send methods.
[Messages & Formatting] Added ephemeral_message_id to ReplyParameters; made message_id optional if ephemeral_message_id is present.
[Messages & Formatting] Added editEphemeralMessageText, editEphemeralMessageMedia, editEphemeralMessageCaption, editEphemeralMessageReplyMarkup, and deleteEphemeralMessage.

--------------------------------------------------------------------------------
June 11, 2026 — Bot API 10.1
--------------------------------------------------------------------------------
[Messages & Formatting] Introduced Rich Messages for highly structured text and AI stream replies.
[Messages & Formatting] Added RichText formatting classes: Bold, Italic, Underline, Strikethrough, Spoiler, DateTime, TextMention, Subscript, Superscript, Marked, Code, CustomEmoji, MathematicalExpression, Url, EmailAddress, PhoneNumber, BankCardNumber, Mention, Hashtag, Cashtag, BotCommand, Anchor, AnchorLink, Reference, ReferenceLink.
[UI/UX]                 Added RichBlock formatting components (Caption, TableCell, ListItem, Paragraph, Heading, Preformatted, Footer, Divider, Math, Anchor, List, Blockquote, Pullquote, Collage, Slideshow, Table, Details, Map, Media blocks, Thinking).
[Messages & Formatting] Added sendRichMessage, sendRichMessageDraft (streaming), and rich_message parameter to editMessageText.
