# FileToLinkV2bot Benchmarks

This directory contains benchmarking scripts and real production performance data for `FileToLinkV2bot`.

## Structure

- `scripts/`: Benchmark runners (e.g. `run_benchmark.py`).
- `data/`: Benchmark results and JSON performance profiles for folder mode, cancellation, and multi-client storage workers.

## Usage

```bash
python benchmarks/scripts/run_benchmark.py
```
